## Tactix Support

With Tactix Support, it's easy to raise a support ticket with screen and audio recording right from within your system.

### Features
- In-app Support Ticket dialog with audio and screen recording.
- Direct synchronization with the Tactix Support Portal.
- User impersonation for System Managers.
- Address & GSTIN fetching utilities.

### Setup

1. Install **Tactix Support** on your site.
2. Go to **Tactix Settings** and check **Enable Ticket Raising**.
3. Configure the **URL** and **API Token** for the Tactix Support Portal.
4. Add a Help dropdown / workspace action:
   - Action: `new tactix.SupportTicket()`
